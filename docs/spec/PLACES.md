**THE BUILD-OUT'S PHYSICAL RULES (normative — mirrored in THE-STATION §3):**
1. **Per-bay triangle budget ≤ `budget.py` `cell_tris` = 60,000** (the streaming cell's
   own ceiling; a bay is at most a cell).
2. **"Distinct" is seeded parametric variation generated at stream time from the
   committed schema — never stored** (ADR 0003; `cell_manifest.note`: "metadata only —
   geometry is generated by deck_cell(), never stored"). The 4.5 GB payload does not grow
   with the tiling; a stored-mesh build-out is a defect by definition.
3. **Full dressing only within sight depth.** STATE.md §13, verbatim: *"tile the bay
   along Z to the location's real length, dress only the bays within sight, and state the
   cap loudly, because CLAUDE.md's own rule is that a silent cap reads as coverage."*
4. **Incremental rebuild:** a schema change re-emits only the cells whose inputs changed
   (the manifest's per-cell hash is the dependency key); a full-station re-emit for a
   one-room edit is a build-system defect.
5. **Shell B per-unit interactables instantiate at stream time with behaviour-LOD:** a
   270-unit block's 270 babcom terminals exist as data always and as scene nodes only
   within the streamed cell; their T3 behaviour binds on instantiation.
