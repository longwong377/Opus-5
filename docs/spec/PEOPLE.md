# THE PEOPLE — normative annex to THE-STATION.md §5 (people) and §6 (roles)

Format law: `docs/THE-STATION.md` §1 (anti-rig — every item is an ID plus an acceptance
check that names enumerated content; statistics are floors on top and complete nothing) and
§2 (depth tiers). Tier tags `[T1]..[T4]` mark the tier an interactable class must reach;
place-level floors (≥1 T4, ≥3 T3 per named place) are enforced row-by-row in the places
annex — this file's staffed interactables are the people-facing half of those rows.
Citations are `file:line` or gazetteer §. Everything uncited and unmarked traces to the
people-domain research return; **(auth 5)** marks invention, per hard rule 1. Place names in
`monospace` are register keys from `station/directory.py`. Cross-references `SYS-xx` are
`docs/spec/SYSTEMS.md`. Era datum for every schedule and armband: **(3,5)**, S3
pre-martial-law (`station/npc/costume.py:167`, `ERA_EVENTS` :147–166).
